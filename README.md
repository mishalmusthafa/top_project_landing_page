# top_project_landing_page
This is the odin project landing page in the foundation

In this project I have created a landing page using flex-box. I have added navbar 4 section and a footer. I have used flex box to align most of the section. The main sections parent element I have used the padding classes for the re-use and to be consistent. 
In this project I have replicated the same like the design image. 

## Challenges:
The Main challenge I have faced is the Hero image size inside the flex box container. The image was going beyond the container or when it is inside a child div the the width of the image is going to be too narrow. It fixed by making the img as direct child of the "hero-flex-container" which has hero-left and image, Also added width and heigh for the image.
